# 审校 SOP：五道关口逐项清单

> 目标：把"通读改错"变成"按类扫查"，让每类差错都有对应的检查动作和判定依据。

## 校次分工

| 校次 | 侧重 | 输出 |
|---|---|---|
| 一校（作者/责任编辑） | 事实、数据、引文、政策口径 | 事实核对单 |
| 二校（文字编辑） | 字词、标点、数字、语句、逻辑 | 字词勘误单 |
| 三校（责任校对） | 名称、职务、提法、图文对应、版式 | 综合审校单 |
| 终校（值班主任/签发人） | 标题、导语、敏感点、整体风险 | 签发意见 |

三审三校不可合并。**同一人不得同时担任同一稿件的二审与三校**。

---

## 第一关：政治关

逐项核对，命中即查原文，不得凭记忆改：

1. **领导人姓名、职务、排序**：姓名用字、职务全称、多人并列时的排序，一律对照权威通稿。
2. **党的创新理论名称**：首次出现用完整表述，不得简称、缩写、改写。
3. **重大会议名称**："届"与"次"的搭配（二十届四中全会 ≠ 二十届四次会议）。
4. **重大提法**：脱贫攻坚、乡村振兴、共建"一带一路"倡议、中国式现代化等，用现行规范提法，
   不用已停用的旧提法（如"一带一路战略"）。
5. **涉台**：不得称"台湾政府""台湾当局政府"；用"中国台湾""台湾地区""台湾当局"；
   "台独"须加引号。
6. **涉港澳**：规范为"中国香港""中国澳门""香港特别行政区"；不得与主权国家并列。
7. **涉民族宗教**：不用"回教""回民"等旧称；用"伊斯兰教""回族群众"。
8. **时间表述**："新中国成立前（后）"，不用"解放前""建国以来"。
9. **疫情防控类旧稿**：核查是否仍在使用已废止的表述。
10. **荣誉称号、表彰名称**：与授奖机关公布的名称逐字一致。

判定原则：**宁可不改，不可乱改**。拿不准的标注"存疑待核"，交签发人处理。

## 第二关：名称关（差错占比最高）

按"扫名称"的方式过稿，不要顺着段落读。

### 人名
- [ ] 同音字、形近字（卢靖／卢婧）
- [ ] 少数民族姓名、外籍人士译名的分隔号"·"
- [ ] 同名人物是否张冠李戴
- [ ] 已故人物的姓名、身份、生卒年

### 地名
- [ ] 行政区划层级与隶属关系（市／区／县，撤县设市后的新名称）
- [ ] 生僻字、多音字
- [ ] 易混地名（湖南张家界 ≠ 湖北；重庆为直辖市）
- [ ] 景区名与行政区名不一致时的表述

### 机构名
- [ ] 首次出现用全称，后文才用规范简称
- [ ] "中国"与"国家"不可互换（应急管理部，非"国家应急管理部"）
- [ ] 机构改革后的新名称（国家金融监督管理总局，非"银保监会"；中央广播电视总台，非"中央电视台"）
- [ ] 不得随意缩写、增字、减字（天津市人大常委会主任，非"天津人大委常委会主任"）
- [ ] 内设机构、直属单位名称是否准确

### 职务名
- [ ] 检察长／院长；主席／主任；书记／局长
- [ ] 兼职表述用"兼任"，并列职务用顿号
- [ ] 已免职、调任的职务是否更新
- [ ] 排序：一般按党委、人大、政府、政协，同级按职务高低

### 文件法规名
- [ ] 全称、年份、发文机关、文号
- [ ] 法律法规用书名号；会议、活动、课题不用书名号

## 第三关：字词关

- [ ] 机检初筛跑一遍 `scripts/check_text.py`
- [ ] 逐条核对机检结果，剔除误报（如"一分钱"不是"一份钱"）
- [ ] 成语、惯用语是否按规范写法（惟妙惟肖、锲而不舍、一鼓作气）
- [ ] 异形词是否统一（按《第一批异形词整理表》）
- [ ] 近义混用：篡改／窜改、暴发／爆发、胜地／圣地、权力／权利、必需／必须
- [ ] 同一篇内同一概念用词是否统一（不要一会儿"患者"一会儿"病人"）
- [ ] 引文是否与原文逐字一致（引文错字比自写错字更严重）

---

## 第四关：标点数字关

### 标点（GB/T 15834—2011）
- [ ] 引号与点号位置：完整引用句号在内，部分引用句号在外
- [ ] 书名号：法规、书刊、篇章名用；会议、活动、奖项不用
- [ ] 书名号内再套书名号用单书名号〈〉
- [ ] 破折号"——"占两字位，不用单横线或连字符
- [ ] 省略号"……"六点占两字位，不用"。。。"
- [ ] 顿号只用于并列词语，并列分句用逗号
- [ ] 分号用于并列分句之间
- [ ] 间隔号"·"用于人名、书名与篇名之间
- [ ] 括号：句内括号紧贴被注内容，句外括号置于句末点号后

### 数字（GB/T 15835—2011）
- [ ] 公历世纪、年代、年月日、时刻用阿拉伯数字
- [ ] 年份不简写（1998年，不写98年）
- [ ] 概数用汉字（三四个、十几个），不加顿号
- [ ] 序数词、成语、惯用语用汉字（第三次、三心二意）
- [ ] 百分数范围两端都带百分号（20%～30%）
- [ ] 数值范围用浪纹线"～"或一字线"—"
- [ ] 计量单位用法定符号（30℃、5千克、10千米）
- [ ] 起止时间用"至"或一字线，不用"－"
- [ ] 小数、千分位、"万""亿"的口径统一

---

## 第五关：业务关

- [ ] 电头规范（当日"本报讯"，非当日"本报×月×日讯"；通讯社稿"新华社×地×月×日电"）
- [ ] 署名：记者／通讯员不得混用，多作者排序与供稿单位一致
- [ ] 时间要素明确，不用"日前""近日""不久前"
- [ ] 消息来源具名，不用"据透露""有关人士称"
- [ ] 体裁与格式匹配（消息不写成通讯，通讯不标"本报讯"）
- [ ] 标题：引题／主题／副题层级正确；标题字词单独校一遍
- [ ] 图片说明：何人、何时、何地、何事齐全；图片与正文人物对应
- [ ] 数据、图表与正文一致；单位、口径、统计年份一致
- [ ] 转载稿注明来源；不得删改原意
- [ ] 链接、二维码、账号名称、版权信息正确

## 常见返工原因（复盘用）

1. 只改字词不改提法 —— 政治差错往往整段重写而非替换词。
2. 机检结果全盘接受 —— 误报会导致"改错"，必须人工判定。
3. 名称只核首次出现 —— 后文简称、二次出现同样会错。
4. 标题不单独校 —— 标题错字影响最大、发现最晚。
5. 引文不回头核 —— 名家引语、文件原话最容易"顺手改错"。
