# 采编勘误审校（qwbxc-caibian-kanwu）

一套面向报纸、网站、新媒体编辑记者的**稿件差错排查流程 + 235 条可机检词库**。
知识体系对标「千万别写错」（微信公众号 ID：qwbxc123，江苏，采编人员培训）的勘误路数：
**先分类、再定位、后统一**，把"凭感觉改稿"变成"按清单过稿"。

词库每周五更新，情报来源见 `references/情报源与周更机制.md`（高校/党政/业界三类账号清单＋巡检 SOP）。

## 何时使用

- 稿件付印/发布前的校次审读（一校、二校、终校）
- 领导讲话稿、政务通稿、重大主题报道的表述合规核查
- 新媒体推文、标题、海报文案的字词体检
- 采编培训授课、差错案例复盘、编校质量抽查
- 需要一份可直接交差的**审校单 / 勘误报告**

## 核心方法：五道关口

差错不是"看出来的"，是"按类扫出来的"。按下列顺序过稿，覆盖率最高、返工最少。

| 关口 | 查什么 | 主要依据 | 对应词库类型 |
|---|---|---|---|
| 一、政治关 | 领导人姓名职务、党的创新理论名称、重大提法、涉台涉港澳涉疆涉藏 | 权威通稿、官方发布 | 政治表述、表述 |
| 二、名称关 | 人名、地名、机构名、职务名、活动名、文件法规名 | 机构官网、官方文件 | 机构名称、职务、专名 |
| 三、字词关 | 错别字、成语误写、异形词、近音近形混用、易错读音 | 《第一批异形词整理表》《通用规范汉字表》 | 错别字、成语、用字、读音 |
| 四、标点数字关 | 引号书名号、破折号省略号、顿号分号、数字用法、计量单位 | GB/T 15834、GB/T 15835 | 标点、数字、计量 |
| 五、业务关 | 电头、署名、时间要素、消息来源、体裁、图文对应 | 新闻业务规范 | 新闻业务 |

名称类差错在实际编校中占比最高（多地政务新媒体检查通报均把"机构名称、政策固定用语、
文字校核"列为问题集中处），**过稿时不要从第一段读到最后一段，而要先整体扫名称**。

详细操作见 `references/审校SOP.md`。

## 工作流

### 1. 机检初筛

```bash
python scripts/check_text.py 稿件.txt          # 控制台清单
python scripts/check_text.py 稿件.txt --md     # 输出 Markdown 审校单
```

脚本按词库做长词优先匹配，输出：行:列、误→正、类型、说明、上下文。
带 ★ 的条目属表述类（政治提法、机构、职务、规范用语），**命中即须核对权威原文**，
不能直接套用替换。

### 2. 人工过五关

对机检未覆盖的部分（逻辑、事实、引文、图文对应）按五道关口逐项核对。
事实类差错机器查不出，必须回到原始信源：文件原文、官网、当事方、现场。

### 3. 出审校单

按 `references/审校SOP.md` 末尾模板输出，区分三类处理：
- **必改**：政治提法、机构职务、事实性错误、专名错误
- **建议改**：字词、标点、语句冗余
- **存疑待核**：需作者或权威源确认的事项（不要擅自改）

### 4. 沉淀

新发现的差错回写 `data/lexicon.json`，然后重新生成对照表：

```bash
python scripts/build_references.py
```

### 5. 每周更新（周五）

词库不是死表，每周从情报源收增量。完整 SOP 见 `references/情报源与周更机制.md`，命令链：

```bash
python scripts/harvest.py            # 采集目标号列表页（验证码会中断，用 --from N 续跑）
python scripts/weekly_digest.py      # 生成 reports/weekly-YYYY-MM-DD.md
python scripts/build_articles.py     # 重建 references/文章清单.md
python scripts/build_references.py   # 重建 6 张对照表 + 统计
```

铁律：**提不出一句话依据的条目不入库**，宁缺勿错。政治提法、机构职务、法规名称
一律回到官方原文核一次，核不到只进周报不进词库。

## 关键判据（易混淆处，务必分清）

- **篡改 / 窜改**：重大抽象内容用作伪手段改动 → 篡改；具体文字材料改动 → 窜改
- **暴发 / 爆发**：传染病、洪水突然大量发生 → 暴发；火山、战争、掌声 → 爆发
- **截至 / 截止**：截至＋时间（截至10月20日）；截止不带宾语
- **胜地／圣地**：风景优美之地 → 胜地；神圣之地（革命圣地延安）→ 圣地
- **权力／权利**：政治上的强制力 → 权力；依法享有的利益 → 权利
- **检察长 / 院长**：检察院用检察长，法院用院长，不可互换
- **作出 / 做出**：公文语体统一用"作出"
- **倍**：只用于增加，不能"减少一倍"，应写"减少一半／减少50%／减少五成"
- **通信 / 通讯**：传递信息统称通信；通讯社、通讯网、新闻体裁用通讯
- **考察 / 视察**：领导人调研多用考察；人大代表、政协委员多用视察
- **督察 / 督查**：中央生态环境保护督察等法定督察用"督察"；一般工作检查用"督查"
- **悬赏 / 通缉 / 拘留**：法院民事执行悬赏、公安机关刑事通缉、行政或刑事拘留，三者性质不同，
  标题与正文都不得混用（2026-10 已有媒体因此致歉）
- **常委会 / 常委会议**：党内法规用语是"常委会会议"，"常委会议"漏一个"会"字
- **截至 / 截止**之外还有一组：**制定 / 制订**（定案用制定，草拟才制订）、
  **亟须 / 急需**（亟须接事项，急需接物品）、**授权 / 受权**（给出去授权，接进来受权）、
  **其他 / 其它**（公文一律用"其他"）

## 边界与免责

- 词库是**线索库**，不是判决书。专有名词、引文原貌、法规条文以权威原文为准。
- 涉政治表述以官方通稿、权威发布为唯一依据；本 Skill 只做提醒，不生成新提法。
- 采集自公众号的原文若与官方口径冲突，一律以官方为准。
